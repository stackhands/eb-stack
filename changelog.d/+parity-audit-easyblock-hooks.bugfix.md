`scripts/parity_audit.py` now runs the easyblock of every targeted recipe: it writes the module with `make_module_step(fake=True)` and compares the module name, module loads and `EBVERSION` with what eb-stack resolved. `--include-easyblocks` adds site easyblocks to discovery and to EasyBuild. A bare `python` run by an easyblock, as `PythonPackage` does, resolves to the audit's own interpreter.
